## R and RStudio for MAC USERS

**Install R**

- Open an internet browser and go to [r-project](https://cran.r-project.org).
- Click **Download R for macOS**
- Click on `R-4.6.2-arm64.pkg` for all newer computers running Apple Chips and `R-4.6.2-x86_64.pkg` for computers running Intel chips. 
- Save the .pkg file, double-click it to open, and follow the installation instructions.

Now that **R** is installed, you need to download and install **RStudio**.

**Install RStudio**

- Go to [RStudio](https://posit.co/products/open-source/rstudio)
- Click on **Download RStudio**
- Click on the version recommended for your system, or the latest Mac version, save the .dmg file on your computer, double-click it to open, and then drag and drop it to your applications folder.
- You want the FREE version, not the commercial version.

## R and RStudio for PC USERS

**Install R**

- Open an internet browser and go to [r-project](https://cran.r-project.org).
- Click the **Download R for Windows**
- Click on **base**
- Click on **Download R-4.6.2 for Windows** and save the executable file somewhere on you computer. Run the .exe file and follow the installation instructions.

Now that **R** is installed, you need to download and install **RStudio**.
  
**Install RStudio**

- Go to [RStudio](https://posit.co/products/open-source/rstudio)
- Click on **Download RStudio**
- Click on the version recommended for your system, or the latest Windows version, and save the executable file. Run the .exe file and follow the installation instructions.
- You want the FREE version, not the commercial version.
